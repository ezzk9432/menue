# Restaurant Menu

A static restaurant-menu website with an accompanying PDF menu.

## Contents

- `index.html`: the browser-based menu, including its page styles and behavior.
- `menu.pdf`: PDF version of the menu.

## Run locally

Open `index.html` in a modern browser, or serve the repository root with a static web server. No package installation or build step is required.

## Stack

HTML, CSS and JavaScript.

## Scope

This repository is a front-end menu presentation. It is not a payment, ordering or restaurant-management backend. Menu prices and availability are sample/project content, not a live offer.

After changing the menu, review it on desktop and mobile and check the PDF separately so the two versions remain consistent.
